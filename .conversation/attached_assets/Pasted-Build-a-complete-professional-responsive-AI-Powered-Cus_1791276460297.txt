Build a complete, professional, responsive AI-Powered Customer Support System as a production-ready web application.

1. Project Objective

Create an AI-powered customer support platform that can automatically understand and respond to common customer queries. When a query is too complex, sensitive, or cannot be confidently answered, the system must automatically escalate the conversation to a human support agent.

The application should demonstrate a complete customer-support workflow from customer query → AI response → confidence evaluation → human escalation → agent resolution.

2. Core Features

Customer Interface

Create a modern customer chat interface with:

- Customer name/profile section
- Real-time chat interface
- Message input box
- Send button
- Loading/typing indicator
- Timestamp for messages
- Conversation history
- Clear conversation option
- Suggested questions/FAQ buttons
- Support ticket creation option

Example common queries:

- "How can I reset my password?"
- "How do I update my account details?"
- "Where can I check my order?"
- "How can I cancel my order?"
- "What payment methods are supported?"
- "How do I request a refund?"

AI Support Agent

Implement an AI chatbot that:

1. Receives the customer's question.
2. Understands the intent.
3. Searches the available FAQ/knowledge base.
4. Generates a helpful response.
5. Assigns a confidence score.
6. Determines whether the query can be handled automatically.

Use a clear response structure such as:

- Answer
- Relevant information
- Suggested next step

If the AI does not have enough information, it must NOT invent an answer.

Intelligent Escalation

Create an escalation system based on AI confidence and query complexity.

Escalate the conversation when:

- AI confidence is below a configurable threshold.
- The customer explicitly requests a human agent.
- The query is outside the knowledge base.
- The issue involves sensitive account/payment problems.
- The customer indicates that the AI response was not helpful.
- The issue requires manual verification.

Example:

AI Confidence: 42%

Status:
"Human agent required"

Show the customer:

"Your request has been forwarded to a human support agent. Please wait while an agent reviews your issue."

12. Important AI Safety Rules

The AI must:

- Never fabricate information.
- Clearly state when it does not know something.
- Escalate uncertain queries.
- Never expose private customer information.
- Never expose API keys.
- Never claim that a human agent has responded unless an actual agent has responded.
- Preserve the full conversation history during escalation.
